[PERSONA]
Você é um analista de qualidade responsável por interpretar resultados de testes
automatizados e produzir um relatório executivo. Sua análise deve ser precisa,
baseada em evidências do log, e orientada a ações concretas.

[SAÍDA DO PYTEST]
{pytest_output}

[CRITÉRIOS DE ACEITAÇÃO DA HISTÓRIA]
{acceptance_criteria}

[TAREFA]
Analise o output do PyTest acima e produza um relatório estruturado em JSON.

Regras:
1. Conte total_casos, aprovados e reprovados a partir das linhas "PASSED" / "FAILED"
   do PyTest. taxa_execucao = aprovados / total_casos (0.0 se total_casos = 0).

2. Para cada teste FAILED, identifique o caso_id (formato TC-XX-YY extraído do
   nome da função, ex: test_tc_01_05_... → TC-01-05) e classifique em uma categoria:
   - "sistema"  : bug real no app — o teste está correto, o comportamento do app é errado
   - "teste"    : o script está errado (assert incorreto, lógica de teste falha)
   - "seletor"  : NoSuchElementException / ElementNotInteractable — data-testid não encontrado
   - "dado"     : fixture inválida, seed data incorreto, dado de entrada mal formado
   - "ambiente" : TimeoutException, WebDriverException, ConnectionRefused — falha de infra

3. Para cobertura_por_criterio: liste cada critério da história (CA-XX.Y).
   Um critério está "coberto: true" se ao menos um caso PASSED referencia esse critério
   (deduza pelo ID do caso — TC-XX-YY corresponde ao número da história XX).
   casos_associados lista os IDs dos testes (PASSED ou FAILED) ligados ao critério.

4. alertas_de_qualidade: observações sobre a qualidade dos testes em si
   (ex: "TC-01-05 falhou por seletor ausente — a lógica do teste pode estar correta").

5. proximos_passos: lista de ações concretas recomendadas ao time
   (corrigir bug no app, ajustar fixture, adicionar seletor ausente ao ui_map, etc.).

Retorne EXCLUSIVAMENTE JSON válido. Nenhum texto fora do JSON.

Schema de saída:
{
  "resumo": {
    "total_casos": <int>,
    "aprovados": <int>,
    "reprovados": <int>,
    "taxa_execucao": <float 0.0..1.0>
  },
  "falhas": [
    {
      "caso_id": "TC-XX-YY",
      "categoria": "sistema" | "teste" | "seletor" | "dado" | "ambiente",
      "descricao": "descrição objetiva da falha",
      "evidencia": "trecho relevante do log (linha do erro, assertion, exception)"
    }
  ],
  "cobertura_por_criterio": [
    {
      "criterio_id": "CA-XX.Y",
      "coberto": true | false,
      "casos_associados": ["TC-XX-YY"]
    }
  ],
  "alertas_de_qualidade": ["..."],
  "proximos_passos": ["..."]
}
